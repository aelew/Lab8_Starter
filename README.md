## How are graceful degradation and service workers related?

Service workers are a tool for graceful degradation on the web. Instead of a full failure when the network goes down, a service worker intercepts requests and serves cached assets instead, letting the app still function offline in a reduced but usable state. In short, service workers are the mechanism that makes graceful degradation on the web practical.
